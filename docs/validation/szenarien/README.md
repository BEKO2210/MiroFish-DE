# Testszenarien für die Validierung

Jedes Szenario beschreibt nur die Ausgangslage vor jeder öffentlichen Reaktion. Erlaubt sind Fakten (Beschluss, Zahlen,
Beteiligte, Nutzung). Nicht enthalten sein dürfen Reaktionen, Forderungen, Ankündigungen, Proteste, rechtliche Hebel
wie Bürgerbegehren oder wertende Wörter – auch nicht als Verneinung („keine Proteste“), weil schon die Nennung das
Modell lenkt. Was davon in den Läufen auftaucht, ist dann ein Ergebnis der Simulation und kein Echo der Eingabe.
