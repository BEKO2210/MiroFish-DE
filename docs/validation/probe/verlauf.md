# Verlauf (fiktiv, wird nicht an die Simulation gesendet)

- Am Tag nach dem Beschluss veröffentlicht der Skateverein eine ablehnende Stellungnahme.
- Nach einer Woche startet eine Bürgerinitiative eine Unterschriftensammlung.
- Der Gemeinderat hebt den Beschluss innerhalb von 14 Tagen nicht auf.
- Nach drei Wochen kündigt die Verwaltung eine Prüfung einer Ersatzfläche an.
